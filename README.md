# El mundo en 1780

Página basada en Hobsbawm, E. (2009). *La era de las revoluciones, 1789-1848*. Buenos Aires: Crítica.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo y sube `index.html`, la carpeta `img/` y este archivo.
2. En *Settings → Pages*, elige *Deploy from a branch*, rama `main`, carpeta `/ (root)`.
3. La página quedará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
